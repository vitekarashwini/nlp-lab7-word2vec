# 🧠 NLP Lab 7 — Word2Vec & Word Embeddings

This project demonstrates **Word2Vec training and analysis**, part of my NLP coursework at Northeastern University.  
It includes:
- Loading and visualizing word embeddings  
- Finding nearest neighbors for selected words  
- Observing semantic similarity behavior

## 🚀 Highlights
- Implemented using Python & Gensim  
- Demonstrates training evidence, vector visualization, and neighborhood queries  
- Screenshots included in `lab7/report/`  
- Clean modular code under `lab7/scripts/`
